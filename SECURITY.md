# Security Policy

## Supported versions

ModernOPT is experimental software. Security fixes are currently considered for the latest code on the default branch. Older commits and development artifacts may not receive fixes.

## Reporting a vulnerability

Please do not publish exploit details in a public issue or discussion.

Use GitHub's **Private vulnerability reporting** feature for this repository if it is enabled. If it is unavailable, contact the maintainer through the contact options on the GitHub profile and ask for a private channel before sending technical details.

Include:
- A concise description and potential impact
- Steps to reproduce or a minimal proof of concept
- Affected commit/build and environment
- Any suggested mitigation, if known

Do not include passwords, access tokens, personal data, or unrelated private information.

## Response expectations

The project is maintained on a best-effort basis. There is no guaranteed response or fix deadline. Please allow reasonable time for review and avoid public disclosure until a coordinated response is possible.

## Scope

This policy covers security issues in ModernOPT itself. Vulnerabilities in Minecraft, NeoForge, Java, graphics drivers, launchers, or other mods should also be reported to their respective maintainers.
