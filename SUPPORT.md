# Support

ModernOPT is experimental and support is provided on a best-effort basis.

## Before asking for help

1. Confirm that you are using Minecraft Java Edition 1.21.1 and a compatible NeoForge version.
2. Test with the latest relevant ModernOPT build and avoid mixing JARs from different commits.
3. Temporarily remove other rendering mods to check whether the issue is reproducible.
4. Include the exact mod list and relevant logs, after removing tokens, account identifiers, private addresses, and other sensitive information.

## Where to ask

- **Bug reports:** [GitHub Issues](https://github.com/Cr512-netizen/ModernOPT/issues)
- **Code changes:** [Pull requests](https://github.com/Cr512-netizen/ModernOPT/pulls)
- **Security issues:** see [SECURITY.md](SECURITY.md)

## What to include

Minecraft and NeoForge versions, ModernOPT commit/build, operating system, GPU and driver, Sodium/Iris versions, shader pack, reproduction steps, expected result, actual result, and a redacted log excerpt.

Please be respectful. The project does not promise compatibility with every mod pack or a response time.
